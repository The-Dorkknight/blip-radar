# Security

Blip runs an open Wi-Fi hotspot protected only by a WPA2 password (default `blipblip`, change it in Settings). There is no login on the web UI; anyone on the hotspot can see the radar picture and change settings. Keep that in mind before leaving a node running.

To report a vulnerability privately, use GitHub's "Report a vulnerability" (Security tab) on https://github.com/The-Dorkknight/blip-radar rather than a public issue.
